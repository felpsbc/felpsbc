## 🚀 Featured Projects

### 🔓 [Vulnerable LLM Application](https://github.com/felpsbc/vulnllm)
Educational web application intentionally vulnerable to **all 10 categories of the OWASP LLM Top 10** — Prompt Injection, Insecure Output Handling, Training Data Poisoning, and more. Each vulnerability ships with full documentation: exploitation path, impact analysis, and remediation guidance.
> `Python` · `FastAPI` · `Docker` · `LLM APIs`

### 🎯 [LLM Prompt Injection Scanner](https://github.com/felpsbc/llm-pi-scanner)
Automation tool that tests chatbot endpoints against a curated payload set mapped to **MITRE ATLAS**. Generates JSON and HTML reports with success rates broken down by attack category — useful both for red teamers and for defenders building their own evaluation pipelines.
> `Python` · `Click` · `Jinja2`
